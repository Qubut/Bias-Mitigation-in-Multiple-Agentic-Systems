classmethod load_merged(cls, base_path, *override_paths, cli_overrides=None)[source]#

Load and merge multiple YAML files with optional CLI overrides.

Files are merged in order: base_path, then each override_path, then cli_overrides. Later values override earlier ones.

Parameters:

  • base_path (str) – Path to the base configuration YAML.

  • *override_paths (str) – Additional YAML files to merge (in order).

  • cli_overrides (dict[str, Any] | None) – Optional dict of CLI overrides (dot-notation keys).

Return type:

MASConfig

Returns:

A fully validated, merged configuration instance.

Example:

config = MASConfig.load_merged(
    'config/base.yaml',
    'config/local.yaml',
    cli_overrides={'intervention': 'mem0g', 'agent_models[0].temperature': 0.7},
)
