Maintenance contract#

Edits to the codebase that require a docs update in the same PR.

Code change

Update

Add / rename an InterventionType member

architecture.md component table; rerun generate-statecharts.

Edit a python-statemachine subclass body

Rerun generate-statecharts; commit the diff under docs/_generated/.

Add / remove a provider on Container or AnalysisContainer

architecture.md DI graph section.

Add / rename _GEPA_METRICS entries (mas/metrics.py)

metrics.md.

Add / rename a public fn in analysis/pipeline.py

architecture.md analysis-pipeline section; analysis/__init__.py re-exports.

Change workflow stages (WorkflowMachine)

Rerun the diagram generator; update architecture.md workflow section.

State-chart generator#

src/scripts/generate_statecharts.py walks the four python-statemachine subclasses and writes one .md file per machine into docs/_generated/. Each file is a MyST snippet containing a fenced mermaid block, ready for {include}.

uv run generate-statecharts

Important

architecture.md {include}-s these files. No hand-drawn mermaid for state machines — re-run the generator instead.
