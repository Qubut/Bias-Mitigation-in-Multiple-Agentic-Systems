Troubleshooting

Troubleshooting#

Each section below is a self-contained recipe — symptom → root cause → fix.

mem0g run hangs at startup

Likely mem0 telemetry blocking on SIGINT. Confirm MEM0_TELEMETRY=False:

MEM0_TELEMETRY=False uv run train --intervention mem0g

Then validate vector-store reachability (chroma path is writable, or the qdrant/postgres URL is reachable) and the embedder endpoint responds to POST /v1/embeddings.

mem0g saturates CPU cores

The evaluator runs through dspy.Evaluate with N worker threads; mem0g adds embedder + vector-store I/O on top. Cap:

evaluator_concurrency:
  max_evaluation_threads: 8
  max_llm_inflight_per_endpoint: 8

For mem0g / mem0g_gepa interventions, evaluation.py additionally sets OMP_NUM_THREADS=1, OPENBLAS_NUM_THREADS=1, MKL_NUM_THREADS=1, NUMEXPR_NUM_THREADS=1 defensively (only when the env var is unset).

'tuple' object has no attribute 'get' in failure rows

Every sample failed with the same AttributeError. The traceback is preserved in stream_failure_rows.jsonl::error since mas/evaluator.py::metric formats the traceback into that field.

Tip

Read the JSONL row rather than the CSV — CSV collapses newlines and truncates the traceback.

Recall / store timeouts dominate the log

Mem0Tools._memory_slot uses a cross-thread threading.BoundedSemaphore — asyncio.Semaphore is loop-local and breaks under dspy.syncify’s per-call event loops.

If you still see [MemoryOrchestrator]: recall timed out after Xs, the embedder is the likely bottleneck. Raise:

memory_orchestration:
  recall_timeout_ms: 8000
  store_timeout_ms: 6000

memory_config:
  memory_slot_timeout_ms: 4000   # must be < recall_timeout_ms
Pressure circuit opens immediately

The pressure breaker trips on consecutive _MemoryBackpressureError events. Inspect Mem0Tools.stats_snapshot() counters:

  • semaphore.wait_timeouts high → raise memory_operation_semaphore_limit and memory_slot_timeout_ms.

  • search.fallback_circuit_open_skips high → the search-fallback circuit (separate from pressure) tripped; extend search_fallback_cooldown_ms or raise search_fallback_consecutive_fail_trip_threshold.

Embedding endpoint flips between 400 and 200

The OpenAI-compatible embedder rejected the dimension override:

memory_config:
  embedder_force_dimensionless_requests: true
  enable_dimension_fallback: true

Mem0Tools._attempt_dimension_fallback_reinit triggers a one-shot re-init without the explicit dimension once a dim-mismatch error is seen.

Sphinx build fails
LC_ALL=C.UTF-8 uv run sphinx-build -M html docs docs/_build -W --keep-going

Then fix any unresolved references or broken toctrees. Regenerate state-machine diagrams when the build complains about missing docs/_generated/*.md:

uv run generate-statecharts
Dataset script ordering

Run in order: download-datasets → ingest-datasets → unify-datasets → split-datasets. Use the same --db-url across all four, the same --seed and --train-ratio across split-datasets invocations within one comparison.
